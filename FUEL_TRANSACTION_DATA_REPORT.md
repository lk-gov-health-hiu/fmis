## Database Schema Analysis

### Key Fields in FUELTRANSACTION Table

- `REQUESTQUANTITY` (double) - Requested fuel amount in liters

- `ISSUED` (boolean) - Transaction has been approved/issued

- `TOINSTITUTION_ID` - Destination institution (if applicable)
- `CANCELLEDINSTITUTION_ID` - Institution that cancelled
- `REJECTEDINSTITUTION_ID` - Institution that rejected

#### Person References
- `REQUESTEDBY_ID` - Person who requested
- `ISSUEDUSER_ID` - Person who approved/issued

#### Vehicle/Driver References

#### Other Fields
- `REQUESTREFERENCENUMBER` (varchar) - Reference number for request

- `INVOICENO` (varchar) - Invoice number

## Appendix: Data Collection Queries

All queries filtered by: `WHERE (RETIRED = 0 OR RETIRED IS NULL)`

### Overall Statistics
```sql
SELECT
  COUNT(*) as 'Total Transactions',
  SUM(ISSUEDQUANTITY) as 'Total Issued Quantity',
  COUNT(CASE WHEN ISSUED = 1 THEN 1 END) as 'Issued Transactions'
FROM FUELTRANSACTION
WHERE RETIRED = 0 OR RETIRED IS NULL;
```

### Fuel Sheds Analysis
```sql
SELECT
  i.NAME as 'Fuel Shed',
  COUNT(ft.ID) as 'Transaction Count',
  SUM(ft.ISSUEDQUANTITY) as 'Total Issued Quantity'
FROM FUELTRANSACTION ft
LEFT JOIN INSTITUTION i ON ft.FROMINSTITUTION_ID = i.ID
WHERE (ft.RETIRED = 0 OR ft.RETIRED IS NULL)
GROUP BY i.ID, i.NAME
ORDER BY COUNT(ft.ID) DESC;
```

### Requesting Institutions Analysis
```sql
SELECT
  i.NAME as 'Requesting Institution',
  COUNT(ft.ID) as 'Transaction Count',
  SUM(ft.REQUESTQUANTITY) as 'Total Requested Quantity',
  SUM(ft.ISSUEDQUANTITY) as 'Total Issued Quantity'
FROM FUELTRANSACTION ft
LEFT JOIN INSTITUTION i ON ft.REQUESTEDINSTITUTION_ID = i.ID
WHERE (ft.RETIRED = 0 OR ft.RETIRED IS NULL)
GROUP BY i.ID, i.NAME
ORDER BY COUNT(ft.ID) DESC;
```
